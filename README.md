Aplicación desarrollada como práctica de introducción a Angular, implementando componentes, servicios y enrutamiento.  

## Objetivo  
Familiarizarse con el entorno de Angular mediante:  
- Creación de componentes (`Home`, `Products`, `ProductDetails`, `Cart`, `About`).  
- Configuración de rutas.  
- Uso de Angular Material y Bootstrap 5.  

##Tecnologías  
- **Frontend**: Angular 16  
- **UI**: Angular Material + Bootstrap 5  
- **Estilos**: SCSS
